A tiny deterministic program that writes one one-line office joke to /output/entry.txt. An AI judge compares the entered jokes head to head on whether the line is a real joke, whether it turns somewhere unexpected, whether it rings true about office life, how tight the wording is and how fresh the take is; the funniest lines take the pool.

## Run it

```sh
python3 main.py
```
